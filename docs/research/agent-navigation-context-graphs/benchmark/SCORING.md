# Frozen harness contract (before outcomes)

Five variants: scoped_rg, map_only (authored router only, no content FTS), lexical, map_lexical, hybrid. Shared top-k=10 and UTF-8 serialized response cap=9600 bytes; no snippets required. Candidate native output recorded separately if envelope normalization is necessary. Full pre-cap rankings recorded as diagnostics, never scored as returned results.

Queries are unchanged task text. Relevance judgments do not enter any retrieval algorithm. Baseline tokenization splits camel case, lowercases alphanumerics, drops a fixed English/navigation stoplist, and singularizes trailing s for words longer than four characters. It selects up to three authored routing prefixes by distinct query-term overlap; absent overlap searches the allowed tracked corpus. Filename score is 3 per distinct matching term; scoped rg content score is 1 per distinct matching term. Sort descending then path. No query-specific synonyms or ground-truth-based scope changes.

Metrics: hit@5/10 and MRR over positive qrels; source and docs metrics filter judgments, NOT returned positions. Graded group coverage@5/10: each group receives maximum retrieved grade divided by its maximum judged grade, then macro-average groups. Ungrouped qrels default to one group per path. Also report unweighted group coverage. Explicit grades <=0 are not relevant. Unjudged paths are not counted relevant (incomplete judgments are a limitation). Macro-average tasks per split; report answerability separately where present. Empty relevant class yields null, not zero.

Three repeated warm queries (configurable 3–5) in cyclically rotated candidate order, also rotating task order each repetition. Cold-query timings mean first process query per task/candidate after index build, NOT dropped OS caches; all are subprocess wall times including interpreter startup. Warm timings mean repeated queries against filesystem cache, not a persistent server. p50/p95 use linear interpolation. Build wall time separate. Record exact serialized UTF-8 bytes and chars/4 estimate explicitly NOT real tokens. Preserve first_run; later runs require new directory. Capture machine/runtime, corpus HEAD and tracked dirty state, runner/prototype/task hashes. Failures retained; no automatic algorithm repair after seeing results.

No fresh agent trials in this harness: deterministic retrieval is not agent success or real token savings. No target writes; caches and results live under benchmark (ignored cache). Scope policy comes from candidate allowlist when exposed, otherwise harness conservative tracked-path policy. Any corpus-policy difference must be disclosed.
